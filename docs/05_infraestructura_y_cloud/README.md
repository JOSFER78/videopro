# ☁️ 05. Infraestructura Cloud, Base de Datos y Topología

> **Propósito:** Documentar la arquitectura de persistencia, almacenamiento de objetos, esquemas de Firebase Firestore y runtime de servicios.

## 📂 Componentes:
- **Firebase Firestore:** Esquemas de colecciones (`videopro_settings`, `videopro_projects`, `providers_registry`).
- **Cloudflare R2:** Almacenamiento distribuido de activos multimedia 4K.
- **Runtime y Puertos:** Servicios activos (Streamlit :7001, Antigravity Bridge :8742, FastAPI backend).
