# 🔬 04. Laboratorio de Investigación y Nuevas Tecnologías

> **Aviso Importante:** Esta carpeta es un banco de recursos vivos, investigaciones avanzadas y tratados de ingeniería sobre tecnologías que **aún no están en la página web**. No es una directriz dogmática ni una biblia sagrada; es material de referencia técnica para inspirar, orientar y evaluar nuevas funciones.

## 📂 Áreas de Investigación (Sin Número de Serie):
- **`visual_y_3d/`**: Shaders GLSL, React Three Fiber, tipografía cinética 3D, consistencia de actores y DoP 7 capas.
- **`audio_y_foley/`**: Psicoacústica 3 capas, catálogo analógico Neumann KM184, sidechain ducking FFmpeg a -22dB y suites 15 min.
- **`motion_y_codigo/`**: Remotion Motion Design, spring physics, prevención de layout shift (`tabular-nums`), cartografía táctil estilo Vox y transiciones WebGL HyperFrames.
- **`benchmarks_y_evaluacion/`**: Comparativas empíricas de FLUX 3 vs Google Flow, LTX-Video, upscale 4K CPU y costes por segundo.
- **`templates/`**: Plantillas estandarizadas para redactar nuevos dossiers de investigación.
- **`SOP_INGESTA_INVESTIGACIONES.md`**: Procedimiento operativo estándar para ingestar y documentar nuevas investigaciones automáticamente.
