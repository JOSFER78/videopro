# 🖥️ 01. Módulos y Motores Activos en la Web UI

> **Propósito:** Documentar el funcionamiento operativo de todas las capacidades y motores que ya están implementados y activos en la interfaz web de VideoPro Studio y registrados en Firebase Firestore.

## 📂 Estructura del Pilar:
- **`capacidades/`**: Las 14 capacidades formales del pipeline (Guion, Google Flow, FLUX 3, NanoBanana, LTX-2.5, Stock, FlowMusic, VibeVoice, Kokoro, Edge-TTS, FFmpeg, Remotion, Subtítulos, Whisper) y sus esquemas JSON.
- **`motores_y_proveedores/`**: Catálogo de los 26 motores del registry clasificados por categorías (`visual`, `music`, `voice`, `programacion`, `llm`, `cloud`).
