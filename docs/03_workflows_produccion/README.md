# 🎬 03. Arquetipos de Producción y Workflows

> **Propósito:** Documentar los 8 arquetipos de producción seleccionables en la pestaña "Workflow Studio" de la web para la creación autónoma de vídeos.

## 📂 Arquetipos Disponibles:
1. `01_CHRONODRIFT_TRITEMPORAL`: Reconstrucción histórica y viajes urbanos temporales 4K.
2. `02_FPV_URBAN_REAL_FLOW`: Vuelos cinemáticos rasantes y tours hiperrealistas.
3. `03_PIXAR_3D_ANIMATION`: Animación procedural 3D con estilo Pixar/Dreamworks.
4. `04_HISTORICAL_SCRAPING`: Documentales con hemerotecas restauradas y B-roll de archivo.
5. `05_DEEP_EXPLAINER_ESSAY`: Ensayos visuales con mapas táctiles estilo Vox y gráficos de datos.
6. `06_VIRAL_SHORTS_HOOK`: Formato vertical 9:16 de alta retención.
7. `07_CITY_ROUTES_BEATS`: Recorridos dinámicos sincronizados al tempo musical.
8. `08_AI_SLOP_PURGE_AND_REMASTER`: Purga de artefactos sintéticos y remasterización 4K.
